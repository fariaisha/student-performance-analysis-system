# Student Performance Analysis System

## Selected Data Mining Technique
Classification

## Three Models
1. Decision Tree
2. Gaussian Naive Bayes
3. Support Vector Machine (SVM)

This is the previously developed Student Performance Analysis project, reorganized for the supplied Data Mining Lab schedule.

### Lab mapping
- Lab 1: Python for Data Mining
- Lab 2: Data Preprocessing and Exploration
- Lab 3: Data Visualization and EDA
- Lab 6: Decision Tree
- Lab 7: Naive Bayes
- Lab 8: SVM
- Lab 12: End-to-End Data Mining Pipeline

Labs 4, 5, 9, 10 and 11 are not selected as separate algorithms because the project instruction asks for one data-mining technique with at least three models under it.

### Run from project root
```powershell
pip install -r requirements.txt
python train_model.py
streamlit run app/app.py
```
